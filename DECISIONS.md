# Decisions

- P0: Use the specified `src/approva` package layout and setuptools editable install so CLI, tests, and Streamlit share one import path.
- P0: Keep the documented default `LLM_MODE=live`; offline tests and demos will explicitly select `stub` or `offline`.
- Differentiation / Laya: Verified the official [Convai Laya model card](https://huggingface.co/convaiinnovations/laya) and typed-decisions card. Use the Apache-2.0 `laya` package API (`laya.load(checkpoint)` then `agent.predict(state, questions)`); `laya>=0.3.20` is isolated in `requirements-laya.txt`. `convaiinnovations/laya-typed-decisions` is the selected checkpoint, but remains optional and disabled by default.
- Differentiation / Laya authority: Laya receives structured Intake fields, never the raw employee text. `log_only` cannot modify the request or decision; `gate` can only add sensitivity/signals/scrutiny or block auto-approval. Unavailable Laya uses a conservative local structured-field fallback and blocks auto-approval in gate mode. This is not a full Tier-2 request extractor/router.
- Differentiation / Gateway: Added one `ALLOW` / `HOLD` / `BLOCK` Decision Gateway. It revalidates the persisted decision, request state, recorded approver identities, roles, executor actor, allowlisted tool, deterministic tool arguments, and idempotency. The registry and each raw side-effect tool require an opaque Gateway-issued permit.
- Differentiation / Attack Lab: The fixed eight-case lab runs cases through `create_request()` and `process_request()`; all counts derive from persisted current-run decisions/status/tool calls. Stub-mode interpretation remains canned and visibly labeled by the existing UI; no live adversarial-model accuracy is claimed.
- Differentiation / Decision Passport: The Passport is read-only and revalidates citations against the current policy corpus before display. It reports the existing global audit-chain result, not a separate per-request chain.
- Differentiation / scope: No new workflow, real provider, enterprise integration, or fine-tuned checkpoint was added. Live Laya inference and performance/accuracy on Approva requests remain unverified.
